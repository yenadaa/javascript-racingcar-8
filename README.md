##자동차 경주
###개요
- 우아한 테크코스 2주차 프리코스 과제 제출본입니다.
- 주어진 횟수 동안 n대의 자동차가 무작위 조건에 따라 전진하거나 멈추는 경주 게임입니다.

## 🚀 기능 목록
### 입력 기능 (InputView.js)
- [x] 사용자에게 '경주할 자동차 이름을 입력하세요.(이름은 쉼표(,) 기준으로 구분)' 라는 문구로 입력을 받습니다.
- [x] 사용자에게 '시도할 횟수는 몇 회인가요?' 라는 문구로 입력을 받습니다.

### 문자열 파싱 기능(Parsing.js)
- [x] 자동차 이름은 쉼표(,)를 기준으로 구분하여 배열에 저장합니다.
- [x] 배열 안 요소를 name으로 잡고 거리를 적을 공간까지 매핑합니다.
### 전진 및 멈춤 기능(RacingGame.js)
- [x] 0에서 9 사이에서 무작위 값을 구합니다. randomNumber()
- [x] 무작위 값이 4 이상일 경우 전진하게 설정합니다. goStop(number)
- [x] n대의 자동차가 전진 또는 멈추게 설정합니다. moveCar(nameDistance) 
- [x] n회 반복하며 경주를 진행합니다. race(nameDistance)
- [x] 각 차수의 진행 상황을 저장합니다.

### 우승자 결정 기능(Winner.js)
- [x] 자동차 경주 게임을 완료한 후 누적 전진 횟수가 가장 많은 우승자를 변수에 저장합니다. (한 명 이상일 수 있다.) 

### 출력 기능(OutputView.js)
- [x] 시도 횟수 입력이 끝나면 공백 한 줄 출력합니다.	
- [x] '실행 결과'라는 안내 문구를 출력합니다.
- [x] 차수별로 저장한 실행결과를 `{자동차 이름1} : ---`형식으로 화면에 출력합니다.
- [x] 각 차수별 실행 결과 사이사이에 공백 한 줄을 출력합니다.
- [x] 최종 우승자는 안내 문구 형식에 맞춰서 출력합니다.
	- [x] 단독 우승자 : `최종 우승자 : {자동차 이름}`
	- [x] 공동 우승자 : `최종 우승자 : {자동차 이름1}, {자동차 이름2}`

## ⚠️ 예외 상황 테스트(Validation.js)

사용자가 잘못된 값을 입력할 경우 "[ERROR]"로 시작하는 메시지와 함께 Error를 발생시킨 후 애플리케이션은 종료되어야 한다.

### 자동차 이름 입력
- [x] 입력받은 자동차가 하나일 경우
- [x] 입력받은 자동차가 빈 문자열''일 경우
- [x] 입력받은 자동차 이름이 중복될 경우
- [x] 입력받은 자동차 이름이 5자를 초과할 경우
- [x] 입력받은 자동차 이름이 없고 쉼표만 있을 경우

### 시도 횟수 입력
- [x] 시도횟수가 숫자가 아닐 경우
- [x] 시도횟수가 0 이하일 경우
- [x] 시도횟수가 정수가 아닐 경우
- [x] 시도횟수가 빈 문자열''일 경우
